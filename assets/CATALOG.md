# Каталог ассетов UltraLauncher

Готовых ассетов к заданию не прилагалось: в ТЗ папку ассетов нужно было создать самостоятельно, и на диске F она не существовала. Поэтому визуальный стиль сделан с нуля: тёмная палитра с зелёным акцентом (`src/UltraLauncher.App/Themes/Colors.xaml`), собственные векторные иконки интерфейса (`Themes/Icons.xaml`) и иконка приложения ниже.

| Файл | Формат | Размер | Применение |
|---|---|---|---|
| `ultralauncher.png` | PNG RGBA | 512×512 | Логотип в боковой панели окна |
| `ultralauncher.ico` | ICO (PNG-кадры) | 16, 20, 24, 32, 40, 48, 64, 128, 256 px | Иконка exe, окна и панели задач |

Иконка генерируется скриптом `scripts/generate-icon.py` (Python + Pillow): изометрический куб со стрелкой «запуск». Регенерация:

```bash
python scripts/generate-icon.py assets
```

Изображения Mojang/Minecraft в проект не включены.
