# Офлайн-аккаунты — изменение UltraLauncher

Основа: https://github.com/ytjhtyjty/UltraLaucher, коммит ab44875.

## Что изменено

- На вкладке «Аккаунты» добавлена форма «Создать офлайн-аккаунт».
- Для создания нужны только 3–16 латинских букв, цифр или символов `_`; Microsoft и Client ID не нужны.
- Профиль сохраняется, автоматически становится активным, повторное создание того же ника не дублирует запись.
- Для ника вычисляется стандартный Minecraft UUID по `OfflinePlayer:<ник>`.
- Локальный профиль не обновляет Microsoft-токены, не требует входа и не отображается как демо или подтверждённая лицензия.
- Старые Microsoft-аккаунты сохраняют прежнюю логику.
- Сохранение профилей по-прежнему защищено Windows DPAPI.

## Как пользоваться

1. Откройте «Аккаунты» → «Создать офлайн-аккаунт».
2. Введите ник и нажмите кнопку создания.
3. На главной выберите версию и нажмите «Установить и играть».
4. Для запуска без сети сначала установите версию и подходящую Java; затем включите «Офлайн-режим».

Создание профиля не требует сети. Загрузка игры и Java требует интернета.
Локальный профиль не предоставляет доступ к Realms и серверам с проверкой лицензии.
UUID локального и Microsoft-профиля различаются: инвентарь и прогресс, привязанные к UUID, могут отличаться.

## Сборка на Windows

Установите .NET SDK 10 и выполните из папки проекта:

```powershell
dotnet test tests/UltraLauncher.Tests
powershell -ExecutionPolicy Bypass -File scripts/build-release.ps1
```

Готовый файл: `dist/UltraLauncher.exe`.
