# UltraLauncher

Лаунчер **Minecraft: Java Edition (vanilla)** для Windows 10/11 x64: список версий из официального манифеста Mojang, установка с проверкой SHA-1, запуск и отслеживание игры, вход через Microsoft, офлайн-запуск ранее установленных версий, настройки, журналы и диагностика.

> Состояние: рабочая версия 1.0.0. Установка, ремонт и запуск игры проверены на реальных данных Mojang. **Вход Microsoft на реальном аккаунте не проверялся**: для этого нужен ваш Client ID и одобрение Mojang (см. ниже). Подробности — в [TESTING.md](TESTING.md).

## Быстрый старт

1. Запустите `dist\UltraLauncher.exe` (установка не нужна, .NET на компьютере не нужен).
2. **Аккаунты → Создать офлайн-аккаунт**: введите ник (3–16 латинских букв, цифр или `_`). Вход Microsoft и Client ID не нужны. Либо выберите **Войти через Microsoft** (для этого настройте Client ID).
3. На **главной** выберите версию и нажмите **Установить и играть** / **Играть**.

Распространять достаточно одного файла `dist\UltraLauncher.exe` (self-contained single-file, ~60 МБ). `dist\SHA256SUMS.txt` — контрольная сумма для проверки.

## Где что хранится

| Что | Где |
|---|---|
| Исходники, документация, релиз | `F:\UltraLauncher` (`src`, `tests`, `dist`) |
| Ассеты проекта (иконка) | `F:\UltraLauncher\assets` |
| Настройки, журналы, кеш, Java от Mojang | `%LOCALAPPDATA%\UltraLauncher` (`settings.json`, `logs\`, `cache\`, `runtimes\`) |
| Аккаунты (зашифрованы DPAPI) | `%LOCALAPPDATA%\UltraLauncher\accounts.dat`, `msal_cache.dat` |
| Игровые файлы и миры | папка игры из настроек, по умолчанию `%APPDATA%\.ultralauncher` |

Папку данных можно переопределить переменной окружения `ULTRALAUNCHER_DATA` (используется в тестах).

> В ТЗ указан путь `C:\Users\Mikhail\Desktop\UltraLauncher` — это путь с другого компьютера. На этой машине проект по заданию создан в `F:\UltraLauncher`, точка входа — `F:\UltraLauncher\dist\UltraLauncher.exe`. Скрипт сборки работает из любой папки.

Официальный `.minecraft` лаунчер не трогает (по умолчанию используется отдельная папка). Указать `.minecraft` в настройках можно; миры, скриншоты, ресурспаки и `options.txt` лаунчер никогда не удаляет.

## Возможности

- **Версии**: официальный манифест `piston-meta.mojang.com/mc/game/version_manifest_v2.json`; по умолчанию только релизы, снапшоты — флажок в настройках. Последний успешный манифест кешируется для работы без сети.
- **Поддерживаемый диапазон**: Minecraft Java Edition **1.8 и новее** (релизы и снапшоты, вышедшие после 2 сентября 2014). Alpha, Beta и версии до 1.8 (устаревшая раскладка ассетов) в списке не показываются и не устанавливаются. Проверено на 26.3 (Java 25) и 1.12.2 (Java 8).
- **Установка**: клиент, библиотеки, natives (оба формата — старый с распаковкой и новый LWJGL 3), ассеты, конфигурация log4j; правила ОС/архитектуры; наследование `inheritsFrom`; SHA-1 и размер каждого файла; 4 попытки с экспоненциальной паузой; контроль «зависшего» соединения; отмена; запись через `*.part` и атомарный перенос; продолжение после обрыва; кеш проверенных файлов (повторно хеши не считаются).
- **Ремонт** («Проверить» на вкладке загрузок): полный пересчёт хешей и докачка повреждённого.
- **Java**: автоматический подбор установленной Java по `javaVersion` версии; если подходящей нет — установка **официальной Java-среды Mojang** (тот же источник, что у официального лаунчера). Ручной выбор `java.exe`/`javaw.exe` с проверкой версии, разрядности и совместимости.
- **Запуск**: корректные аргументы JVM/игры (каждый аргумент отдельно — пути с пробелами и кириллицей безопасны), память `-Xms/-Xmx`, доп. аргументы JVM, отслеживание процесса, журнал игры (XML log4j преобразуется в читаемые строки), поиск отчёта о сбое, защита от двойного запуска.
- **Интерфейс**: главная, загрузки, аккаунты, настройки, диагностика/логи; тёмная тема, анимации, состояния наведения/фокуса/загрузки/ошибки/недоступности; недоступные действия отключены с объяснением; PerMonitorV2 DPI.

## Вход Microsoft

Используется OAuth 2.0 Authorization Code + PKCE для публичного desktop-клиента через **MSAL.NET** (официальная библиотека Microsoft). Вход проходит в системном браузере на странице Microsoft; лаунчер пароль не видит и не запрашивает. Клиентский секрет не используется. Далее: Xbox Live → XSTS → Minecraft Services (`login_with_xbox`) → проверка покупки (`entitlements/mcstore`) → профиль.

Реальный Client ID в поставку **не входит** — его нужно получить самостоятельно:

1. Войдите на <https://portal.azure.com> → **Microsoft Entra ID → Регистрация приложений → Новая регистрация**.
2. Имя: `UltraLauncher` (любое). Поддерживаемые типы учётных записей: **«Только личные учётные записи Майкрософт»** (или «…в любом каталоге организации и личные учётные записи»).
3. URI перенаправления: платформа **«Общедоступный клиент/собственный (мобильные и классические приложения)»**, значение `http://localhost`.
4. В разделе **Проверка подлинности** включите «Разрешить потоки общедоступных клиентов» = **Да**. Секреты и сертификаты не создавайте.
5. Скопируйте **Идентификатор приложения (клиента)** — GUID.
6. **Одобрение Mojang.** Новые Client ID должны быть допущены к Minecraft Services: заявка — <https://aka.ms/mce-reviewappid>. До одобрения шаг `login_with_xbox` возвращает HTTP 403 — UltraLauncher покажет «Minecraft Services отклонил вход для этого приложения».
7. В UltraLauncher: **Настройки → Расширенные → Client ID** → Сохранить.

Ошибки входа объясняются понятным языком: отмена входа, нет профиля Xbox, детская учётная запись без семейной группы, регион, неодобренное приложение, нет игры (доступна только **демо-версия**), игра куплена без созданного ника, истёкшая сессия.

**Хранение секретов.** Кеш токенов MSAL шифруется Windows DPAPI (пакет `Microsoft.Identity.Client.Extensions.Msal`). Токен Minecraft и данные профиля — в `accounts.dat`, зашифрованном DPAPI для текущего пользователя Windows. Токены регистрируются в фильтре журналов и заменяются на `***` во всех логах, в отчёте диагностики и в журнале игры. «Выйти» удаляет аккаунт из кеша MSAL и из `accounts.dat`.

## Офлайн-режим

- Работает только для **полностью установленной** версии (есть маркер завершения установки и все файлы нужного размера). Сеть при этом не используется.
- Можно использовать **локальный офлайн-аккаунт**, созданный по нику без Microsoft, либо Microsoft-аккаунт с ранее подтверждённой покупкой Minecraft. Локальный профиль не содержит токенов, не считается подтверждённой лицензией и не предоставляет доступ к Realms и серверам с проверкой лицензии.
- Для первой установки игры и автоматической установки Java нужен интернет. После установки выберите на главной **Офлайн-режим**, чтобы запускать без сети. Само создание профиля не требует интернета.
- Ограничения: недоступны мультиплеер, Realms и загрузка скинов; сессия Minecraft могла истечь — она обновится при следующем онлайн-запуске.
- Если файлов не хватает, лаунчер объясняет, что нужна установка онлайн.

## Сборка из исходников

Нужен **.NET SDK 10** (проверено на 10.0.401), Windows 10/11 x64.

```bash
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1
```

Скрипт запускает автотесты, публикует self-contained single-file сборку `win-x64` и кладёт `dist\UltraLauncher.exe` + `SHA256SUMS.txt`. Флаг `-SkipTests` пропускает тесты.

Разработка: `dotnet build UltraLauncher.slnx`, тесты — `dotnet test` (см. [TESTING.md](TESTING.md)).

## Ограничения и известные проблемы

- Вход Microsoft не проверен на реальном аккаунте (нужен Client ID + одобрение Mojang + участие пользователя).
- Масштаб Windows 125%/150% проверен только косвенно (манифест PerMonitorV2, вёрстка в окне эквивалентного размера); на реальном изменённом масштабе не проверялся.
- Forge/Fabric/NeoForge/модпаки/Bedrock не поддерживаются (вне объёма). Версии до 1.8 не поддерживаются.
- Быстрая проверка перед запуском сверяет наличие и размер файлов; полный пересчёт хешей — при установке и по кнопке «Проверить».
- На ARM64 Windows не проверялось (сборка — win-x64).
- Квик-плей, собственное разрешение окна игры и несколько профилей/инстансов не реализованы.
