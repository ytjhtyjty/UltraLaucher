# TESTING.md — проверки UltraLauncher

Среда проверки: Windows 11 Pro 10.0.26200 x64, 16 ГБ ОЗУ, масштаб экрана 100%, .NET SDK 10.0.401, Temurin JDK 21.0.3 и 25.0.4, доступ в интернет. Дата: 21.10.2026. Актуальный релиз Mojang на момент проверки — **26.3** (требует Java 25).

Тестовая песочница: `F:\UltraLauncher Проверка\` (папка игры `Папка игры` — путь с пробелом и кириллицей; данные лаунчера — `data`, через `ULTRALAUNCHER_DATA`). Реальные данные пользователя (`%LOCALAPPDATA%\UltraLauncher`, `.minecraft`) не использовались.

## Как повторить проверку входа Microsoft (нужен пользователь)

1. Зарегистрируйте приложение и получите одобрение Mojang (README → «Вход Microsoft»).
2. Вставьте Client ID: Настройки → Расширенные → Сохранить.
3. Аккаунты → «Войти через Microsoft» → войдите в браузере (пароль вводится только на странице Microsoft).
4. Ожидаемо: аккаунт с игрой — «Лицензия подтверждена», «Играть» запускает игру; аккаунт без игры — «только демо», кнопка «Играть (демо)».
5. Офлайн: после успешного онлайн-входа отключите сеть → «Офлайн-режим» → «Играть».
